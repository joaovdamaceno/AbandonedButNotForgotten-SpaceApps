1. Integrar prefabs/builders aprovados, sem copiar cenas inteiras sobre as alterações dos colegas.
2. Resolver IDs, eventos e referências com os contratos globais; apenas um dono de input/câmera/áudio em cada estado.
3. Revisar nomes de cenas, ordem de build e descarte de memória entre capítulos.
