## Passos de implementação

1. Limitar a resolução interna inicial a 1280×720, usar uma luz principal com sombras e desabilitar SSAO e profundidade de campo no perfil Leve.
2. Compilar Release com IL2CPP e Brotli. Registrar tamanho real dos arquivos e conferir MIME e Content-Encoding no servidor local.
3. Provar material opaco, solo, áudio após gesto do usuário e pausa. Guardar capturas reais para detectar mundo invisível ou coberto por uma cor uniforme.
4. Verificar a plataforma ativa e os shaders incluídos depois de alternar Windows → Web. Distinguir claramente limite configurado, medida neste dispositivo e desempenho ainda não homologado.

## Critérios de aceite

- [ ] O Web abre em Chrome e Firefox sem erros observados.
- [ ] Os shaders de cor necessários ao mundo não foram removidos.
- [ ] O relatório identifica dispositivo e separa orçamento configurado de FPS medido.

## Como verificar

- Compilar depois de trocar o alvo de Windows para Web.
- Testar cache vazio e tela física 4K, mantendo o teto interno de 1280×720.
