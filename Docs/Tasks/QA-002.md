# QA-002 — Automatizar progressão, tecla mantida, pausa, cancelamento e descarte

**Função:** R7 — Ciência, áudio, QA e desempenho · **Prioridade:** P0 · **Estimativa:** 1.5 h-pessoa (revisável).

## Prompt para execução

Novo jogo independente para computador no navegador, em WebGL/itch.io, produzido por sete pessoas. São três capítulos de 5–7 minutos cada, com legendas PT/EN e controles acessíveis para público leigo. Não usar vídeos pré-renderizados ou locução de IA. Esta tarefa implementa infraestrutura compartilhada; não copiar o projeto anterior inteiro. Ler o contexto mestre e os contratos aprovados antes de editar arquivos. R7 protege os contratos comuns antes de os capítulos se integrarem. Testes de estados isolados e operadores automáticos são úteis, mas não demonstram compreensão de novatos.

Leia primeiro o [contexto mestre](https://github.com/joaovdamaceno/AbandonedButNotForgotten-SpaceApps/blob/main/Docs/01_MASTER_CONTEXT.md) e o [AGENTS.md](https://github.com/joaovdamaceno/AbandonedButNotForgotten-SpaceApps/blob/main/AGENTS.md). O novo jogo ainda precisa ser implementado; não presumir sistemas da edição anterior.

Testes comportamentais do núcleo e um harness para os capítulos, com falhas visíveis e identificação da build testada.

## Passos de implementação

1. Provar idempotência, entrada mantida entre etapas, dependências de progresso e reinício. Conferir que um hold não conclui duas ações.
2. Abortar a jornada após um bloqueio fatal. Não gerar PASS para sistemas que não chegaram a executar.
3. Separar testes de estado isolado, percurso com operador automático e partidas de novatos. Documentar preparação de estado, mocks e qualquer ajuda aplicada pelo harness.
4. Incluir hash da build e escopo real nos logs. O relógio do capítulo não pode concluir automaticamente objetivos para fazer o teste passar.

## Critérios de aceite

- [ ] Os testes detectam um hold que atravessa duas etapas.
- [ ] Não há erros conhecidos de referência nos caminhos aprovados.
- [ ] Logs identificam a build e o que foi efetivamente exercitado.

## Como verificar

- Executar Edit Mode e Play Mode e registrar uma falha controlada.
- Conferir que nenhum teste completa objetivos apenas pelo relógio do capítulo.
