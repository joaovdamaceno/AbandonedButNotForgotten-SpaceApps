## Passos de implementação

1. Adicionar microanimações e revelação de folha com duração inferior a 250 ms, respeitando a opção de movimento reduzido.
2. Usar fotografias, recortes e linhas técnicas discretas. Não construir uma sala 3D para apresentar o menu.
3. Preservar o foco de teclado, a interação existente e todas as atribuições dos recursos.
4. Comparar com o layout anterior e reverter qualquer ornamento que esconda o botão ou atrase a decisão do avaliador.
